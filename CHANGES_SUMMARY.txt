API ENDPOINTS (ALL TESTED & WORKING)

POST /api/auth/register
  Request: { fullName, email, password, role: "employee"|"admin" }
  Response: { success, message, token, user: { id, fullName, email, role } }
  Status: ✅ Working

POST /api/auth/login
  Request: { email, password }
  Response: { success, message, token, user: { id, fullName, email, role } }
  Status: ✅ Working

GET /api/auth/me
  Headers: Authorization: Bearer [token]
  Response: { success, user: { id, fullName, email, role, skills } }
  Status: ✅ Working

  2. Open http://localhost:3000/2-login/login.html
  3. Try demo login or create new account

  2. Email: demo@selftrack.com

  5. Verify data in MongoDB Atlas
